# Project Structure

This document defines the initial engineering framework for FLEM-ProtoNet.

The project now contains a minimal runnable pipeline for VOC2007 pre-extracted
features: dataset loading, multi-label episode sampling, FLEM-ProtoNet forward,
training, evaluation, and checkpoint writing.

## Directory Layout

```text
FLEM-ProtoNet-MultiLabel-FewShot/
  README.md
  configs/
    voc2007_feature.json
  scripts/
    demo_random_episode.py
    train.py
    evaluate.py
  src/
    data/
    models/
    training/
    utils/
  docs/
  experiments/
  datasets/
    data/
```

## Directory Responsibilities

### `configs/`

Stores experiment configuration files.

Current modules:

- `voc2007_feature.json`: default VOC2007 ResNet50 feature experiment config.

Configuration contents:

- dataset paths
- episode sampling settings
- model hyperparameters
- optimizer settings
- loss weights
- evaluation settings

### `scripts/`

Stores executable entry scripts.

Current modules:

- `demo_random_episode.py`: tensor-only random episode smoke demo.
- `train.py`: episodic training entry for pre-extracted VOC2007 features.
- `evaluate.py`: episodic evaluation entry for pre-extracted VOC2007 features.

### `src/data/`

Stores data-related modules.

Current modules:

- `dataset.py`: loads pre-extracted multi-label feature datasets such as VOC2007
  ResNet50 features and sparse multi-hot labels.
- `sampler.py`: samples multi-label support/query episodes while keeping full
  multi-hot labels.

Planned responsibilities:

- multi-label dataset loading
- label metadata loading
- support/query episode construction
- few-shot multi-label sampling logic

### `src/models/`

Stores model-related modules.

Planned responsibilities:

- feature encoder
- label enhancement module
- label-wise prototype construction
- multi-label prototype scoring

Current modules:

- `encoder.py`: Conv4 feature encoder adapted from the ProtoNet implementation.
- `flem_protonet.py`: main FLEM-ProtoNet forward module.
- `feature_projector.py`: projects pre-extracted feature vectors into the
  prototype embedding space.
- `label_enhancer.py`: LE module adapted from the FLEM implementation.
- `distance.py`: Euclidean distance and cosine similarity helpers.
- `prototypes.py`: label-wise weighted prototype construction and query scoring.

### `src/training/`

Stores optimization-related modules.

Planned responsibilities:

- training loop
- validation loop
- loss composition
- checkpoint handling

### `src/utils/`

Stores shared utilities.

Planned responsibilities:

- metrics
- reproducibility helpers
- logging helpers
- tensor shape checks

Current modules:

- `metrics.py`: multi-label metrics adapted from the FLEM implementation.

### `docs/`

Stores design documents, notes, diagrams, and project explanations.

### `experiments/`

Stores experiment records.

Recommended contents:

- run notes
- metric summaries
- ablation tables
- configuration snapshots
- checkpoints generated by training scripts
